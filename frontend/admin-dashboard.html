📖 NEW: Paragraph-Based Questions (Reading Comprehension)

For questions that share a reading passage:

  1. Choose a unique GROUP ID for the 10 questions
    Examples: arabic_para_1, science_reading_5, eng_story_3
  2. Question 1: Include GROUP tag + PARAGRAPH tag + question
    [GROUP:arabic_para_1][PARAGRAPH]Full paragraph text here...[/PARAGRAPH]السؤال الأول: ماذا قرأ أحمد؟
  3. Questions 2-10: Include ONLY the GROUP tag + question
    [GROUP:arabic_para_1]السؤال الثاني: أين كان يجلس أحمد؟
  4. Important: All 10 questions MUST have the exact same GROUP ID

✅ Full Example (3 questions):

Q1: [GROUP:para1][PARAGRAPH]قرأ أحمد قصة جميلة عن الصداقة. كان يجلس تحت الشجرة.[/PARAGRAPH]السؤال ١: ماذا قرأ أحمد؟

Q2: [GROUP:para1]السؤال ٢: أين كان يجلس أحمد؟

Q3: [GROUP:para1]السؤال ٣: عن ماذا كانت القصة؟

Result: Students will see the paragraph at the top (sticky), and all 10 questions displayed below it.

Excel Format Requirements:

Your Excel file should have these columns:

  • subject: math, science, english, or arabic
  • grade: 4-9
  • questionType: multiple_choice, true_false, or text_input
  • questionTextEn: Question in English (can include LaTeX)
  • questionTextAr: Question in Arabic (can include LaTeX)
  • correctAnswer: The correct answer (LaTeX delimiters will be removed automatically)
  • option1, option2, option3, option4: (for multiple choice only)
  • imageUrl: (optional)
